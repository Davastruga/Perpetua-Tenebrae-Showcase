# Perpetua Tenebrae Showcase v2.4

1. Sustituye en GitHub Pages los archivos anteriores por los de este paquete.
2. Todo va en la raíz del repositorio.
3. Abre la web en Chrome y vuelve a instalarla si quieres asegurar que usa la v2.4.
4. Configuración se abre directamente desde el engranaje, sin contraseña.
5. Dentro de Configuración tienes Install app, Offline check y almacenamiento persistente.
6. La barra de volumen del menú está en la zona inferior, separada de las tarjetas.
7. El PDF cambia de página con deslizamiento; mientras renderiza, el fondo permanece negro.
