# PERPETUA TENEBRAE SHOWCASE — HTML/PWA v2.1

Esta es la versión recomendada para la tablet Samsung. No necesita APK.

## Qué incluye
- Instalable desde Chrome como aplicación.
- Funciona offline después de instalar y completar el Offline Check.
- Pitch PDF renderizado dentro de la propia app, página a página.
- Swipe izquierda/derecha para el Pitch.
- Logo sustituible por PNG/WebP con controles de tamaño, X e Y.
- Vídeos Combat/Exploration y slots adicionales.
- Fondo, música, sonido de botones y tipografía configurables.
- Contraseña: WhiteCrow26.
- Manifest en modo fullscreen y petición adicional de pantalla completa al tocar la app.

## Instalación en Samsung
1. La carpeta debe estar publicada en una URL HTTPS.
2. Abre esa URL con Chrome.
3. Menú ⋮ > Instalar aplicación / Añadir a pantalla de inicio.
4. Abre PT Showcase desde el icono creado.
5. Entra en Configuración (WhiteCrow26) e importa el PDF, vídeos, logo y fondo.
6. Pulsa OFFLINE CHECK.
7. Activa modo avión, cierra la aplicación y vuelve a abrirla para comprobarla.

## Importante sobre el PDF
El visor usa PDF.js. La primera vez que abras la aplicación con Internet, el motor PDF se almacena en la caché de la PWA. Después puede utilizarse offline.

## Publicarlo sin anuncios
GitHub Pages es suficiente y no añade banners a la aplicación. Sube estos archivos al repositorio y activa Settings > Pages > Deploy from a branch > main / root.
